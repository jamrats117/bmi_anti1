# ระบบคำนวณดัชนีมวลกาย (BMI) พร้อมพรีวิวและพิมพ์ PDF

เว็บแอปพลิเคชันคำนวณดัชนีมวลกาย (Body Mass Index - BMI) ตามเกณฑ์มาตรฐานคนเอเชียและกระทรวงสาธารณสุขไทย รองรับการระบุข้อมูลชื่อ-นามสกุล เพศ อายุ น้ำหนัก ส่วนสูง พร้อมระบบออกรายงานสุขภาพและพรีวิวเอกสารขนาด A4 ก่อนสั่งพิมพ์หรือบันทึกเป็นไฟล์ PDF

## ฟีเจอร์เด่น
- 👤 **ข้อมูลผู้รับการประเมิน**: รองรับการกรอกชื่อ, นามสกุล, เพศ, อายุ, ส่วนสูง และน้ำหนัก
- 📊 **การประเมินค่า BMI แม่นยำ**: คำนวณตามเกณฑ์คนเอเชีย (Asian BMI criteria) 5 ระดับ (ผอม, ปกติ, น้ำหนักเกิน, อ้วนระดับ 1, อ้วนระดับ 2)
- ⚖️ **วิเคราะห์น้ำหนักมาตรฐาน**: คำนวณช่วงน้ำหนักที่เหมาะสมตามส่วนสูง (Ideal Weight Range)
- 🥗 **คำแนะนำสุขภาพเฉพาะบุคคล**: ข้อแนะนำด้านโภชนาการและการออกกำลังกายตามผลการประเมิน
- 📄 **พรีวิวและพิมพ์ PDF**: มีหน้าต่างพรีวิวเอกสารรายงานสุขภาพทางการขนาดมาตรฐาน A4 และปุ่ม Print/Save as PDF ในตัว รองรับการพิมพ์โดยตรงผ่านเบราว์เซอร์อย่างคมชัด

## เทคโนโลยีที่ใช้
- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**

## วิธีการรันโปรเจกต์ในเครื่อง (Local Development)

1. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```

2. รันโหมด Development:
   ```bash
   npm run dev
   ```

3. Build สำหรับ Production:
   ```bash
   npm run build
   ```

## การนำไป Deploy (Vercel / Netlify / Cloudflare Pages)

### Deploy ผ่าน Vercel:
1. ไปที่ [Vercel](https://vercel.com) แล้วลงชื่อเข้าใช้ด้วย GitHub
2. กด **Add New Project** แล้วเลือก repository `jamrats117/bmi_anti1`
3. ตั้งค่า Build Command เป็น `npm run build` และ Output Directory เป็น `dist`
4. กด **Deploy**
